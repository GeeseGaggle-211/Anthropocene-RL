This is a bounded mechanical test on disposable checkpoint copies, not native
curriculum training. No model, optimizer, reward or checkpoint from a probe is
promoted or copied back. Frozen train-only health-probe-v2 supplies observations.

Select each seed's final checkpoint and the scheduled checkpoint with the greatest
single actor/critic layer saturation (earliest boundary breaks ties); deduplicate.
At most6checkpoints. For each independently restore model, Adam moments, sampler
and shuffle states. Use13tasks: workforce; movement; quote enable, partner, offered
and requested good, lot and price; activities0/4/5/9; capital control0. Other native
heads remain explicitly outside this cultivation bank's coverage.

Select the largest common nondegenerate legal face (minimum16rows), sort by the
most variable input feature, and take at most32evenly spaced rows with balanced
labels. Use the first two LEGAL choices. Fix label orientation opposite the initial
observation-conditioned preference, before any update. Critic targets are frozen
initial predictions plus the same balanced labels. All targets remain fixed.

Each task permits64ordinary Trainer.update calls using the retained Adam state,
original learning rates, epochs, minibatches, entropy, gradient clipping and KL
stop. Resample on-policy and recompute old likelihoods before every update. The
artificial actor advantage is centered signed choice/share difference toward the
label's target. Disabled quote branches receive no task evidence; requested-good
evidence requires both targets legal under the actually sampled offered good.
Never force quote enabling or score canonical disabled zeros as choices.

critic residual MSE must be<.9, versus initial1. This crossing avoids mistaking
entropy-only flattening of a negative preference for learned reversal. Require
at least128active samples, including16per label, else report insufficient exposure,
not numerical collapse. Keep per-update exposure, reward variance, head gradients,
KL stops and value errors for attribution. Failed or uncovered cases block an
unqualified adaptation claim and require diagnosis, not silent threshold changes.
